# 💰 Daily Hisab (দৈনিক হিসাব খাতা)

> **দৈনন্দিন আয়-ব্যয় ও দেনা-পাওনা হিসাব খাতা** - Modern, Offline-First, Bilingual Personal & Business Finance Progressive Web App (PWA).

---

## ✨ Features (মূল সুবিধাসমূহ)

- ⚡ **Offline-First & Zero Latency**: ইন্টারনেট ছাড়াই ১০০% কাজ করে; IndexedDB (`Dexie.js`) এর মাধ্যমে ডাটা ব্রাউজারে সুরক্ষিত থাকে।
- 📱 **PWA Installable**: মোবাইল ও কম্পিউটারের হোমস্ক্রিনে কোনো অ্যাপ স্টোর ছাড়াই সরাসরি ইন্সটল করা যায়।
- 🇧🇩 **Bilingual (বাংলা ও English)**: এক ক্লিকে বাংলা ও ইংরেজি ভাষার মধ্যে পরিবর্তন। সুন্দর বাংলা ফন্ট (Hind Siliguri) সংযুক্ত।
- 💵 **টাকা ও কারেন্সি সাপোর্ট**: ডিফল্ট ৳ (BDT) সহ $, €, ₹ ইত্যাদি কারেন্সির সুবিধা।
- 📊 **ড্যাশবোর্ড ও বাজেট ট্র্যাকিং**:
  - মোট জমা (আয়), মোট খরচ (ব্যয়) ও অবশিষ্ট ক্যাশ ব্যালেন্স।
  - মাসিক বাজেট লিমিট এবং ৮০% বা ১০০% অতিক্রম করলে সতর্কবার্তা।
- 📝 **দ্রুত লেনদেন এন্ট্রি**:
  - আয়, ব্যয় ও ট্রান্সফার।
  - কুইক অ্যামাউন্ট বাটন (+৫০, +১০০, +৫০০, +১০০০)।
  - ক্যাটাগরি আইকন, পেমেন্ট মাধ্যম (ক্যাশ, বিকাশ, নগদ, রকেট, ব্যাংক)।
  - ক্যামেরা/গ্যালারি থেকে ভাউচার বা রসিদের ছবি আপলোড (স্বয়ংক্রিয় কম্প্রেসড)।
- 🤝 **দেনা-পাওনা / বাকি খাতা (Debt Ledger)**:
  - "আমি পাবো" (Receivable) বনাম "আমাকে দিতে হবে" (Payable)।
  - ব্যক্তির নাম, ফোন নম্বর, পরিশোধের সম্ভাব্য তারিখ এবং আংশিক/সম্পূর্ণ কিস্তি সমন্বয়।
- 📈 **রিপোর্ট ও এক্সপোর্ট**:
  - ক্যাটাগরিভিত্তিক ডোনাট/পাই চার্ট ও আয় বনাম ব্যয় ট্রেন্ড চার্ট (Recharts)।
  - সরাসরি **PDF স্টেটমেন্ট** ও **Excel (XLSX)** ফাইল ডাউনলোড।
- 🔐 **নিরাপত্তা ও ব্যাকআপ**:
  - ৪-সংখ্যার সিকিউরিটি পিন কোড (App PIN Lock)।
  - ওয়ান-ক্লিক JSON সম্পূর্ণ ডাটা ব্যাকআপ ও রিস্টোর।

## 🚀 How to Run (চালানোর নিয়ম)

### ১. ডেভেলপমেন্ট সার্ভার চালু করতে:
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ঠিকানায় চালু হবে।

### ২. প্রোডাকশন বিল্ড ও প্রিভিউ:
```bash
npm run build
npm run preview
```

## 📂 Project Architecture

```
├── prompt.md                     # মাস্টার প্রম্পট স্পেসিফিকেশন
├── architecture.md               # সিস্টেম আর্কিটেকচার ও স্কিমা ডিজাইন
├── src/
│   ├── components/
│   │   ├── auth/PinLockScreen    # ৪-সংখ্যার পিন লক স্ক্রিন
│   │   ├── common/CategoryIcon   # ক্যাটাগরি আইকন ম্যাপার
│   │   ├── dashboard/            # ব্যালেন্স কার্ড, বাজেট ও সাম্প্রতিক লেনদেন
│   │   ├── debts/DebtsView       # দেনা-পাওনা লেজার ও সেটেলমেন্ট মোডাল
│   │   ├── layout/               # হেডার ও বটম নেভিগেশন বার
│   │   ├── reports/ReportsView   # Recharts চার্ট ও এক্সপোর্ট
│   │   ├── settings/SettingsView # ভাষা, কারেন্সি, বাজেট ও ব্যাকআপ
│   │   └── transactions/         # ট্রানজ্যাকশন মোডাল ও সার্চ/ফিল্টার ভিউ
│   ├── context/AppContext.tsx    # গ্লোবাল অ্যাপ স্টেট ও থিম
│   ├── db/db.ts                  # Dexie.js IndexedDB স্কিমা ও ক্যাটাগরি সিড
│   ├── lib/                      # পিডিএফ, এক্সেল, ক্রিপ্টো ও ইমেজ কম্প্রেসার
│   ├── locales/translations.ts   # বাংলা ও ইংরেজি সম্পূর্ণ ডিকশনারি
│   └── types/index.ts            # টাইপস্ক্রিপ্ট ডাটা মডেল
```
